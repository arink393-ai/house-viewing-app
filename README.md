# 🏠 看房紀錄 App

租屋用的單頁紀錄工具，手機開網頁就能用，不用安裝、不用註冊。內含兩種模式：

- **🏠 房客模式（找房）** — 看房檢查表，22 大類，含社會住宅資訊、入住前拍照點交、退租確認
- **🔑 房東模式（篩選房客）** — 租客篩選表，9 大類，含入住點交拍照與退租比對

兩邊資料分開儲存、互不干擾，頂端一鍵切換。

👉 **線上使用：** https://arink393-ai.github.io/house-viewing-app/

## 功能

### 共用
- **拍照點交**：入住前 19 項逐項拍照，拍完自動打勾；退租時可與入住照片並排比對，標記「狀況相符／有新增磨損／需說明」，處理押金爭議用
- **模式切換**：房客／房東兩套表單與評分，資料各自獨立
- **照片**：現場拍照或從相簿上傳，存在裝置本機
- **列印紙本**：兩種模式都能印空白表格或已填紀錄，表頭自動對應

### 房客模式（找房）

- **20 大類檢查表**：基本資料、租金與所有費用、房屋本身、採光通風、噪音環境、冷氣、家具家電、水壓衛浴、廚房、陽台、寵物條件、大樓管理、房東房仲、修繕責任、租約條件、拍照清單、現場紅旗、第一印象、最終評分、下一步
- **0–100 綜合評分**：以 12 項星等平均為基礎，再依紅旗數（每項 −4，最多 −40）、看房直覺（＋5 ～ −15）、寵物條件（0 ～ −15）自動加減，不是單純加總
- **排名與置頂推薦**：自動算名次、標示獎牌，把目前最推薦的物件釘在最上面
- **紅旗警訊**：19 項現場警訊勾選，列表直接顯示 🚩 數量
- **全台縣市＋行政區**：22 縣市、368 個行政區，選了縣市之後行政區自動跟著換
- **從 591 匯入**：貼上物件網址一鍵匯入，**手機 App 分享的 591.to 短網址也支援**（讀不到時可改貼頁面文字），自動解析租金、坪數、格局、樓層、屋齡、電梯、水電費等 29 個欄位，並自動命名物件暱稱，填入前逐項確認
- **照片**：現場拍照、從相簿上傳，或把 591 的物件照片一鍵下載到本機；照片存在裝置的 IndexedDB，會一起放進備份
- **地址查附近交通**：填好地址後一鍵查最近捷運站、公車站與估算步行時間（OpenStreetMap 圖資）
- **自訂標籤**：除了預設選項，可以自己加標籤
- **每欄備註**：任何欄位都能展開寫補充說明
- **捷運站建議**：輸入時自動提示站名
- **怎麼問**：整理好看房時該問房東／房仲的問題，點一下複製
- **列印紙本表格**：印出空白表格現場手寫（完整版約 7 頁、現場精簡版約 3 頁），也可以把已填好的紀錄印出來；可自選要印哪幾區
- **匯出／匯入**：JSON 備份可換手機、CSV 可用 Excel 或 Google 試算表開啟

### 房東模式（篩選房客）

- **7 大類檢查表**：租客基本資料、職業與財力、租屋需求、看房當天印象、需要留意的狀況 🚩、信用與租屋經驗、決定
- **0–100 綜合評分**：以禮貌、溝通、提問合理度三項星等平均為基礎，再依警訊數量、準時度、財力證明、整體感覺加減分
- **推薦人選排行**：自動排名，把目前最合適的租客排在最上面

## 資料存在哪裡

所有紀錄只存在**你自己手機或電腦的瀏覽器**，不會上傳到任何伺服器。

- **表單欄位** → localStorage（很小，只有文字）
- **所有照片**（點交、退租比對、相簿）→ IndexedDB（容量以 GB 計）

照片只在紀錄裡留一個參照，實際影像放在 IndexedDB。實測 3 筆紀錄、114 張點交照片，
localStorage 只佔 6 KB、IndexedDB 佔 21 MB —— 若照片存在 localStorage，
21 MB 會遠超過 iOS Safari 約 5 MB 的上限而存不下。

舊版把照片存在紀錄裡的資料，第一次開啟新版時會自動搬移，不需要手動處理。

⚠️ 請注意：
- 清除瀏覽器資料 = 紀錄和照片都會不見，建議定期用選單「匯出備份」（備份含照片）
- 換手機／換瀏覽器不會自動同步，要用匯出 + 匯入


## 加到手機主畫面

已設定完整的 PWA manifest 與 App 圖示，加到主畫面後就跟原生 App 一樣：獨立視窗、沒有網址列、有專屬圖示。

- **iPhone（Safari）**：分享 → 加入主畫面
- **Android（Chrome）**：網址列會直接跳出「安裝應用程式」，或從右上角選單 → 安裝應用程式

## 兩個自動填入功能的限制

**從 591 匯入** — 手機 App 分享的 `591.to` 短網址會先經 microlink 展開成物件頁網址（瀏覽器不能跨域讀取轉址）；頁面文字則經 r.jina.ai 取得，591 圖片則透過 images.weserv.nl 代理下載（591 本身都沒開放跨域）；這兩個服務會看到你查的網址，讀不到時請改用貼上頁面文字。解析刻意**不解析「提供設備／家具」清單**。591 用刪除線標示未提供的項目，複製成純文字後刪除線會消失，照抄會把「無電梯」讀成「有電梯」。設備請自己在 ⑦ 家具與家電 勾選。刊登寫「可養寵物」一律填成「需確認」，因為那只是刊登內容、還沒跟房東談定。

**地址查交通** — 結果是**系統推估值**。台灣門牌號在 OpenStreetMap 中常常查不到，只能定位到巷弄或路段，誤差可能數百公尺；距離為直線距離換算步行時間，不是實際步行路線。實測同一個物件，591 標示「景平站 403 公尺」，而依圖資定位算出最近的是「永安市場 796 公尺」— 落差很大，**現場請自己確認**。

## 列印紙本

看房時想用手寫、或想讓房東看到你有在逐項記錄，可以從右上角 `⋯` → 「列印紙本表格」印出 A4 表格。

- **空白表格**：選項印成 ○ 圈選、勾選項印成 ☐、評分印成 ☆☆☆☆☆，直接在紙上圈寫
- **已填的紀錄**：選到的選項會變成 ● 並加粗、勾選變 ☑、星等填實，適合回家整理或跟家人討論
- 印之前會先告訴你大概幾頁，可以只印需要的分區

## 離線可用

裝了 Service Worker，**第一次開過之後就算完全沒網路也能用**。看房時常在收訊差的大樓或地下室，一樣可以照常填寫紀錄。

## 技術

單一 `index.html`，原生 HTML／CSS／JavaScript，無框架、無相依套件。

```
index.html        App 本體（含全部畫面與邏輯）
manifest.json     PWA 設定：名稱、圖示、主題色、獨立視窗
sw.js             Service Worker：離線快取
icons/            App 圖示（192／512／maskable／apple-touch／favicon）
```

> 換圖示或改 `manifest.json` 之後，記得把 `sw.js` 裡的 `CACHE` 版本號往上加（例如 `house-viewing-v2`），舊快取才會被清掉。
